# LLM Wiki 색인

작업 시작 전 여기서 관련 노트를 찾는다. 규칙은 [[스키마]], 사용법은 [[위키 사용법]].

## 개념

계산 계약과 도메인 규칙. 시점과 무관하게 현재 계약을 서술한다.

- [[총수익률과 배당수익률]] — `totalReturn`과 `dividendYield`를 더하지 않는다

- [[원장 불변식]] — 모든 자금 이동은 보존식을 깨지 않는다

## 결정 (ADR)
