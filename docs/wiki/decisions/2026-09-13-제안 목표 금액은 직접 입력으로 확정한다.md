# 제안 목표 금액은 직접 입력으로 확정한다

## 결정

목표 카드에서 제안 금액을 그대로 수락하는 별도 확정 버튼을 제공하지 않는다. 목표 금액의 출처는
사용자가 입력창에 직접 금액을 입력하고 Enter를 누르거나 입력창을 벗어났을 때만 `user`로
기록한다. 제안된 숫자를 그대로 목표로 쓰려면 그 금액을 직접 입력해야 한다.

## 배경

제안 금액은 계획에서 가져온 초기값이다. SOFT 목표에서는 확정 전후 차이가 화면에서 즉시 드러나지
않아 별도 확정 버튼의 기능이 모호하게 느껴질 수 있었다. 금액 입력을 마치는 동작만 출처 확정으로
남겨, 사용자가 실제로 목표로 삼은 금액을 직접 입력하도록 한다.

HARD 금액 목표는 사용자가 확정한 금액만 강제 조건이 된다는 계약은 유지한다. 씨앗이 사용자
확정값으로 승격되지 않으므로, HARD 목표의 미확정 금액은 계속 분석을 막는다.

## 기각한 대안과 범위 제외

- 제안값을 변경하지 않고 확정하는 별도 버튼은 제거한다.
- 출처 구분이나 HARD 확정 관문을 제거하지 않는다. 이들은 시스템 초기값이 강제 조건으로
  승격되는 것을 막는 계산 계약이다.

## 호환성 처리

저장 필드와 기존 시나리오는 변경하지 않는다. 기존 미확정 금액은 그대로 미확정이며, 입력을
직접 완료한 기존 사용자 금액은 계속 확정으로 읽힌다.
