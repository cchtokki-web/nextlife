# 목표 카드에서 제안 금액 안내를 간소화한다

## 결정

목표 카드의 「아직 제안 금액입니다」 설명 문단을 제거한다. 참고 금액과 `금액 수정` 동작은
유지하고, 미확정 HARD 목표에는 금액 확인 요구를 계속 표시한다. 금액의 출처 판정과 사용자 입력
완료를 통한 확정 동작은 바꾸지 않는다.

## 배경

목표 금액 입력창과 카드에 참고 금액이 함께 표시되어 안내 문단은 반복 정보로 판단했다. HARD 목표의
확인 요구와 금액 수정 동작을 남겨 사용자가 확정할 수 있는 흐름은 유지한다.

## 기각한 대안과 범위 제외

- 확인되지 않은 금액을 확정값으로 취급하지 않는다.
- 별도 제안 금액 수락 버튼을 다시 추가하지 않는다.
- 계산·저장 계약은 변경하지 않는다.

## 호환성 처리

데이터 형식, 저장 시나리오, 계산 경로는 변경하지 않는다. 기존처럼 목표 금액을 직접 입력하고
Enter를 누르거나 포커스를 이동해야 확정된다.

## 영향받는 개념
