# 자동 시세 반영 대상을 현재 계획으로 확장한다

## 결정

자동 시세 반영을 켠 경우 시나리오를 열 때 현재 계획의 ETF를 조회한다. 기준 계획 저장 여부와
관계없이 작동하며, 저장 후 추가하거나 종목을 바꾼 ETF도 조회한다. 조회 중 사용자가 종목·
통화·단가를 변경한 항목은 기존과 같이 건너뛴다.

## 배경

기준 계획을 처음 저장한 뒤 추가된 ETF가 자동 시세 반영에서 빠지면 현재 계획 전체를 갱신할
수 없다. 기준 계획은 비교를 위해 보존하고 조회 대상은 현재 계획에서 가져온다.

## 기각한 대안과 범위 제외

과거 적립, 배당, 분할, 수량, 취득원가를 자동 갱신하지 않는다. 열린 화면에서 새로 추가한
ETF는 시나리오를 다시 열 때 조회한다. 가격이나 시각이 없거나 통화가 다르면 반영하지 않는다.

## 호환성 처리

기존 자동 반영 설정을 유지하며 미지정 시 꺼진다. 기준 계획은 변경하지 않는다. 기존에 설정을
켠 시나리오에서는 추가된 현재 ETF도 조회 대상이 되므로 결과가 달라질 수 있다.
