# 자동 전략 최적화 실행을 중단한다

## 결정

현재 계획 분석에서 자동 페르소나 전략 최적화 Worker를 실행하지 않고 화면과 PDF의
해당 추천 영역을 내지 않는다. 사용자가 요청하는 목표 변경안 비교는 유지한다.

## 배경

사용자는 별도의 자동 전략 후보 검증 기능을 더 이상 사용하지 않기로 했다.

## 기각한 대안과 범위 제외

기존 엔진과 Worker를 삭제하지 않는다. 현재 계획의 Monte Carlo, 목표 변경안 비교,
기존 센티널 설정의 legacy 계산 경로는 유지한다.

## 호환성 처리

저장 시나리오와 기존 전략 설정의 형식은 변경하지 않는다. 생산 경로만 분리한다.
