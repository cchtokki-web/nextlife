# 사용자 카테고리 수익률을 별도로 보존한다

## 결정

선택한 보수적·중립·공격 유형의 카테고리별 값만 표시한다. 수정한 값은 해당 유형의
값을 복사한 사용자 설정에 저장하고 사용자 버튼을 활성화한다. 다시 유형을 선택하면
기존 유형 값이 적용되며 사용자 버튼으로 수정값을 복원할 수 있다.

## 배경

여러 유형의 값을 한 화면에서 반복해 표시하면 모바일에서 입력 대상을 알아보기 어렵다.

## 기각한 대안과 범위 제외

수정값으로 기존 유형의 값을 덮어쓰지 않는다. 자동 수익률은 기존 ETF별 과거 수익률을 쓴다.

## 호환성 처리

새 선택 모드와 사용자 수익률은 선택 필드이며 기존 시나리오를 불러올 때 추가하거나 수익률을
변경하지 않는다. 완전한 사용자 설정만 복원하며 적용한 총수익률은 기존 계산 입력으로 저장한다.
미분류 자산과 ISA·연금은 사용자 카테고리 설정을 적용할 때 변경하지 않는다.
