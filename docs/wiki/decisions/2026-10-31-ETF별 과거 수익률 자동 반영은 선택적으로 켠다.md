# ETF별 과거 수익률 자동 반영은 선택적으로 켠다

## 결정

사용자가 일반계좌 ETF별로 자동 반영을 켜면 시나리오를 열 때 수정 종가의 과거 연환산
수익률을 다시 조회한다. 1년 미만·누락 관측치·마지막 관측일이 30일보다 오래된 자료는
반영하지 않는다. 30일은 예측 가정이 아닌 오래된 자료를 거르는 조회 기준이다. 날짜와 누락,
반영 여부를 화면에 표시하며 배당률은 변경하지 않는다.

## 배경

사용자가 과거 실적을 미래 가정으로 사용하기로 선택한 ETF는 매번 다시 입력하지 않도록 한다.
과거 실적은 미래 성과를 보장하지 않으며 자료 완전성은 확인되지 않았음을 안내한다.

## 기각한 대안과 범위 제외

기본값을 자동으로 바꾸지 않는다. 부족하거나 오래된 자료에 기본 수익률을 만들어 넣지 않는다.
수익률에 배당률을 더하거나 가격·수량·취득원가를 바꾸지 않는다. 조회 중 수익률이나 배당률을
수정하거나 모드를 끄면 이전 응답을 덮어쓰지 않는다.

## 호환성 처리

ETF별 선택은 시나리오에 선택적으로 저장하며 기존 데이터에서는 꺼진다. 직접 수익률 입력,
일괄·개별 프리셋 또는 조회값 직접 적용 시 해당 자동 모드를 해제한다. 자동 설정은 과거
입력값의 출처를 증명하지 않는다. 시세와 수익률이 함께 갱신될 때 같은 계획에 반영한다.
