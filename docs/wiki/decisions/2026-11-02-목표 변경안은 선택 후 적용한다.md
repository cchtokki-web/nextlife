# 목표 변경안은 선택 후 적용한다

## 결정

기존 목표를 유지하는 전략 추천과 별도로, 사용자가 요청하면 은퇴 시점 또는 확정된 단일
생활비 목표 변경안을 검증한다. 변경된 목표의 확률과 판정 기준을 표시하고 사용자가 고른
안만 적용한다. 적용 후 변경 전으로 복구하거나 현재 목표를 확정할 수 있다. 확정은 목표를
그대로 두고 복구 이력을 지운다. 복구는 같은 화면에서 설정을 수정하거나 새로고침하기 전까지다.

## 배경

필수 은퇴 목표보다 늦은 은퇴와 생활비 목표 감소는 기존 목표를 지키는 전략이 아니다.
목표를 바꾼 확률을 기존 목표의 개선으로 표시하면 비교 기준이 달라진 사실이 감춰진다.

## 기각한 대안과 범위 제외

목표를 자동으로 완화하거나 미확정 금액을 확정하지 않는다. 복구 이력의 서버 저장과
여러 생활비 목표를 함께 바꾸는 제안은 포함하지 않는다.

## 호환성 처리

새 저장 필드 없이 기존 목표 편집과 정규화 경로를 사용한다. 사용자 입력을 선택 전까지
바꾸지 않고 기존 시나리오는 그대로 읽는다. 계산은 브라우저 워커에서 수행한다.
