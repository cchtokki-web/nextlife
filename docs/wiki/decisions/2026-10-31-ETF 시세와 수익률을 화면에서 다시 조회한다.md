# ETF 시세와 수익률을 화면에서 다시 조회한다

## 결정

사용자가 ETF 시세 참고 화면에서 다시 조회할 수 있다. 현재 시점의 기준 ETF와 자동 시세 반영
대상, 자동 수익률을 켠 ETF를 기존 방식으로 다시 조회한다. 자동 반영이 켜져 있으면 새 결과를
기존 검증을 거쳐 현재 계획에 반영하고 필요한 경우 재분석한다.

## 배경

조회 실패를 재시도하거나 화면을 연 뒤 추가한 ETF를 확인하려고 시나리오를 다시 열 필요를 줄인다.

## 기각한 대안과 범위 제외

주기적인 백그라운드 조회, 실제 거래 내역과 수량의 자동 갱신은 제공하지 않는다. 조회 중
새 요청을 시작하면 이전 요청의 결과는 버린다.

## 호환성 처리

기존 자동 반영 설정을 유지하며 설정이 꺼져 있으면 조회만으로 계획을 변경하지 않는다.
조회 중 직접 수정한 단가·수익률을 보호하는 기존 규칙을 유지한다.
