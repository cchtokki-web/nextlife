# 개인정보는 출생연도와 기대수명으로 입력한다

## 결정

개인정보 화면에서 출생연도와 기대수명을 입력한다. 현재 나이 입력과 출생연도 해제 버튼은
표시하지 않는다. 출생연도 입력 시 기존 방식대로 현재 연도에서 빼어 내부 나이를 계산한다.

## 배경

사용자가 해마다 나이를 수정할 필요를 줄이고 입력 항목을 단순하게 유지한다.

## 기각한 대안과 범위 제외

생일 정보가 없으므로 만 나이로 표시하거나 기존 나이에서 출생연도를 역산해 저장하지 않는다.

## 호환성 처리

출생연도가 없는 기존 시나리오는 저장된 나이를 유지한다. 출생연도를 입력해야 이후 연도별
자동 갱신을 사용한다. 기존 데이터 형식과 계산 엔진 입력은 유지한다.
