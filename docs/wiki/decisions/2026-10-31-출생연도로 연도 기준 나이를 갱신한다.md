# 출생연도로 연도 기준 나이를 갱신한다

## 결정

출생연도는 선택 입력이다. 입력되었다면 시나리오를 적재할 때 현재 연도에서 이를 빼어 현재
나이를 계산한다. 생일 정보가 없으므로 만 나이라고 부르지 않는다. 사용자 기기의 현지 연도를
사용하며, 열린 화면에서 연도가 바뀐 경우 다시 열 때 갱신된다.

## 배경

해가 바뀔 때마다 사용자가 직접 나이를 고치지 않아도 현재 계획을 다시 분석하기 위해서다.
이 값은 수명까지의 시뮬레이션 기간에 영향을 준다.

## 기각한 대안과 범위 제외

기존 나이에서 출생연도를 역산해 사용자 입력으로 저장하지 않는다. 출생일, 정확한 만 나이와
열린 탭의 연도 변경 감지는 이 단계에 포함하지 않는다. 나이 계산은 자동 자산 갱신과 별개다.

## 호환성 처리

출생연도가 없으면 기존 나이를 유지한다. 사용자는 선택을 해제하고 나이를 직접 입력할 수 있다.
투자 비교 기준의 저장된 나이는 변경하지 않는다.
