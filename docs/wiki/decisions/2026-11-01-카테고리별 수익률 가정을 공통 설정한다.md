# 카테고리별 수익률 가정을 공통 설정한다

## 결정

일반 투자자산에 사용자가 여섯 카테고리 중 하나를 지정한다. 보수적·중립·공격별
총수익률을 카테고리마다 변경할 수 있다. 중립 초기값은 대표지수·성장/테마·배당주·
개별 주식/기타 6%, 인컴 5%, 채권 3%이다. 보수적·공격은 중립 대비 각각 -2·+2%p다.
사용자에게 제안한 중립 가정과 기존 프리셋의 간격으로 만든 비교값이며 전망치가 아니다.
미분류 자산은 기존 공통값을 사용하고 ISA와 연금은 기존 프리셋을 유지한다.
자동 수익률 모드는 기존 ETF별 과거 수익률을 사용한다. 카테고리 자동 분류는 하지 않는다.

## 배경

서로 다른 투자 성격의 자산을 공통 가정으로 분석하면서 카테고리별 차이를 설정한다.

## 기각한 대안과 범위 제외

비교 가정을 기관 전망치로 주장하거나 투자 상품을 추정해 자동 분류하지 않는다.

## 호환성 처리

새 필드는 선택 사항이다. 기존 자산의 수익률과 분류를 로드 시 변경하지 않는다.
일괄 가정을 선택하면 계산 입력인 totalReturn에 반영되며 저장과 정규화를 거쳐
기존 엔진·Worker가 동일한 입력을 사용한다. 배당은 총수익률에 중복해서 더하지 않는다.
