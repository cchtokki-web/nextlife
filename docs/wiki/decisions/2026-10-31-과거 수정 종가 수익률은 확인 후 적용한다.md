# 과거 수정 종가 수익률은 확인 후 적용한다

후속 결정 [[2026-10-31-ETF별 과거 수익률 자동 반영은 선택적으로 켠다]]가 자동 반영을 추가했다.

## 결정

기존 과거 시세 API에 수정 종가를 선택적으로 추가하고, 브라우저의 공용 계산으로 최초·최종
유효 관측치의 실제 날짜를 이용해 누적 및 연환산 수익률을 계산한다. 1년 미만이나 잘못된
자료에서는 값을 만들지 않는다. 누락 관측치 수를 표시하고 사용자가 직접 적용할 때만 연
총수익률을 바꾼다. 기존 연 배당률은 유지한다.

## 배경

기존 조회는 서로 다른 기간의 가격 성장률과 배당률을 더하고 기본값 및 상한을 적용해 실제
과거 총수익률과 다르다. [Yahoo 설명](https://help.yahoo.com/kb/SLN28256.html)에 따르면
수정 종가는 분할과 분배금을 조정한다. 원천 차트 자료의 완전성과 운용사 공시와의 일치는
확인되지 않았으므로 과거 추정치로 표시한다.

## 기각한 대안과 범위 제외

기존 조회 API 의미를 바꾸거나 가격 성장률에 배당률을 추가하지 않는다. 기본 수익률, 음수
절삭이나 수익률 상한을 넣지 않는다. 개인 세금·거래비용, 미래 예측 및 자동 수익률 갱신은
제공하지 않는다. 장중 마지막 관측치는 확정 종가가 아닐 수 있다.

## 호환성 처리

기존 시세 API 필드는 유지하며 수정 종가만 추가한다. 기존 저장값은 사용자가 적용하지 않으면
변하지 않는다. 배당률을 유지하므로 적용 후 사용자가 적절성을 확인할 수 있게 안내한다.
