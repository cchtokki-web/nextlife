# ETF 자동 수익률 선택에 시세 반영을 통합한다

후속 결정 [[2026-11-01-ETF 시세와 배당률은 자동 조회하고 총수익률은 공통 설정을 따른다]]가 시세 조회 범위를 변경했다.

## 결정

공통 자동 수익률을 선택하면 시나리오를 열거나 다시 조회할 때 현재 계획 ETF의 시세도
함께 반영한다. 시세 자동 반영 체크박스와 성공 상태 설명은 표시하지 않는다.

## 배경

같은 ETF를 자동 갱신하기 위해 두 설정을 따로 켤 필요를 없앤다. 성공한 종목마다 반복되는
조회 설명을 줄이고, 조회 실패는 기존 값을 유지했다는 안내로 표시한다.

## 기각한 대안과 범위 제외

실제 거래·적립·배당 이력이나 수량은 갱신하지 않는다. 부족한 과거 자료는 사용하지 않는다.

## 호환성 처리

공통 선택이 없는 기존 시나리오는 저장된 시세 자동 반영 설정을 유지한다. 사용자가 공통
프리셋을 선택하면 자동 반영을 끈다. 이전 수익률 복원 버튼은 표시하지 않으며 저장 데이터는
삭제하지 않는다.
