# ETF 시세 자동 반영은 선택적으로 켠다

## 결정

사용자가 자동 반영을 켜면 시나리오를 열 때 기준 계획에 포함된 ETF의 새 시세를 조회해,
현재 계획과 식별자·티커·통화가 일치하고 조회 중 변경되지 않은 자산의 현재 단가에 반영한다.
현재 입력으로 분석이 실행 중이거나 완료된 경우 갱신된 입력으로 다시 분석한다.

## 배경

시세를 매번 직접 입력하거나 반영 버튼을 누르지 않아도 현재 계획을 볼 수 있게 한다.
시세 조회 중 사용자가 변경한 단가를 늦은 응답으로 덮지 않는다.

## 기각한 대안과 범위 제외

수량·적립·배당·분할·취득원가는 갱신하지 않는다. 기준 계획에 없는 ETF는 조회하지 않는다.
열린 화면을 유지하는 동안 주기적으로 갱신하지 않으며, 계획 대비 진행도를 계산하지 않는다.
조회 실패나 통화·시각 불일치는 해당 자산을 건너뛴다.

## 호환성 처리

미지정 또는 잘못된 설정은 꺼진 상태다. 기존 시나리오 결과는 자동으로 변경되지 않는다.
설정만 바꿀 때는 분석 입력 해시를 바꾸지 않지만, 실제 단가가 바뀌면 재분석한다.
