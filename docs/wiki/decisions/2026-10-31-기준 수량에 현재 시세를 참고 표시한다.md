# 기준 수량에 현재 시세를 참고 표시한다

## 결정

사용자가 저장한 기준 계획의 ETF 수량에 현재 시세를 곱한 참고값을 표시한다. 해당 ETF의
기준 수량과 시세 통화가 일치하고 시세의 기준 시각을 확인할 수 있을 때만 계산한다. ETF별
통화를 그대로 표시하고 서로 다른 통화를 더하지 않는다.

## 배경

자동 적립과 배당·분할 추정에 필요한 원천 데이터의 조정 기준이 아직 검증되지 않았다.
기준 수량과 시세만으로 보여 줄 수 있는 값을 해당 한계와 함께 제공한다.

## 기각한 대안과 범위 제외

적립·매매·배당·분할 이후의 실제 수량이나 평가금으로 표시하지 않는다. 해당 참고값은
계획 대비 진행도나 은퇴 분석 입력으로 사용하지 않는다. 시세나 기준 시각이 없거나 통화가
다르면 금액을 보여 주지 않는다.

## 호환성 처리

기준 계획을 저장한 경우에만 표시한다. 기존 시세 API의 응답에 선택적 시각 정보를 추가하며
기존 필드는 유지한다. 서버에 종목만 요청하고 보유 수량이나 시나리오는 전달하지 않는다.

PDF에 반영하지 않는다.
