# ETF 자동 수익률을 공통 설정으로 선택한다

## 결정

사용자는 공통 설정에서 보수적·중립·공격 또는 ETF 자동 수익률을 선택한다. 자동은 각 ETF의
과거 수정 종가로 계산한 연환산 수익률을 기존 품질 검증 후 총수익률에 적용한다. ETF의
총수익률과 배당률은 읽기 전용이며 기존 프리셋·자동 조회로 변경한다.

## 배경

ETF마다 설정을 반복하지 않기 위함이다. 자동은 현재 가격이나 미래 예측이 아니라 각 종목의
과거 수익률이다. 배당률과 비 ETF 수익률은 자동 선택으로 변경하지 않는다.

## 기각한 대안과 범위 제외

현재 가격을 수익률로 취급하지 않는다. 과거 자료가 부정확하거나 불충분한 경우 임의의
수익률을 만들지 않는다. 실제 수량이나 거래 내역을 갱신하지 않는다.

## 호환성 처리

공통 선택은 선택 필드로 저장하며 기존 시나리오에는 값을 만들어 넣지 않는다. 기존 ETF별
자동 선택과 저장 수익률을 보존한다. 공통 프리셋이나 이전 수익률을 선택하면 자동 모드를
해제한다. 기존 직접 입력값 복원 기능은 이전 수익률 버튼으로 유지한다.
