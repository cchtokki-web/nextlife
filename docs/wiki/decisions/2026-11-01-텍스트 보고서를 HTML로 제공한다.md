# 텍스트 보고서를 HTML로 제공한다

## 결정

기존 이미지 기반 PDF와 별도로 동일한 보고서 내용을 텍스트 HTML로 다운로드한다. 두 형식은
페이지 재배치와 넘침 검사를 함께 사용한다. HTML은 새 의존성 없이 브라우저에서 생성한다.

## 배경과 한계

이미지 PDF는 본문 검색과 선택이 어렵다. HTML은 본문 텍스트를 보존하지만 실제 브라우저의
인쇄·한글 표시와 화면 읽기 도구 동작은 검증하지 않았으므로 접근성 준수를 주장하지 않는다.
페이지 크기와 글꼴이 달라지면 출력과 페이지 참조가 달라질 수 있다.

## 기각한 대안과 범위 제외

이미지 PDF를 텍스트 PDF로 교체하지 않는다. 실제 화면 읽기 도구와 브라우저 인쇄 검증은
별도로 필요하다.

## 호환성 처리

기존 PDF 다운로드와 계산 결과는 유지하며 HTML은 별도 선택지다. HTML은 기존 보고서의 내용을
사용하고 금융 계산을 복제하지 않는다.
