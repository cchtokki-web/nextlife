# ETF 시세와 배당률은 자동 조회하고 총수익률은 공통 설정을 따른다

## 결정

현재 계획 ETF의 단가와 최근 1년 배당률 추정치를 공통 설정과 무관하게 시나리오를 열 때
또는 새로고침할 때 조회한다. ETF 단가·총수익률·배당률 입력은 읽기 전용이다. 총수익률은
보수적·중립·공격 가정 또는 자동 과거 수익률 중 사용자가 선택한 공통 설정을 따른다.

## 배경

최신 ETF 상태를 반복 입력하지 않고 확인하면서 선택한 가정이 시뮬레이션에 반영되게 한다.
배당률은 과거 1년 분배금 합계를 조회된 시세로 나눈 추정치이며 원천 사건 완전성은 미검증이다.

## 기각한 대안과 범위 제외

기존 API의 기본 배당률을 관측값으로 취급하지 않는다. 1년 미만 자료, 미확인 분배 사건,
오래된 시세 또는 조회 실패 시 배당률을 유지한다. 배당률을 총수익률에 더하지 않는다.
실제 거래·수량·취득원가는 갱신하지 않는다.

## 호환성 처리

기존 API 필드를 유지하고 관측 배당률을 선택적으로 추가한다. 저장 데이터 형식은 변경하지
않으며, 자동 갱신은 현재 ETF의 시뮬레이션 결과를 바꿀 수 있다. 조회 중 값이 바뀌거나
대상이 바뀌면 해당 이전 응답을 적용하지 않는다.
