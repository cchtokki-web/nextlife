# 추천 경로를 단계적으로 통합한다

## 결정

현재는 두 추천 경로를 유지한다. `useStrategyPipeline`의 legacy Utility 추천은 기존 자동
sentinel·현재 계획 분석·저장 호환에 사용하고, `StrategyOptimizer`의 목표 기반 추천은
전략 추천 카드와 PDF 추천 섹션에 사용한다. 두 결과를 하나의 추천으로 합치지 않는다.
자동 보완 정책은 사용자가 직접 설정하지 않은 sentinel 축만 채우는 것으로 확정한다. 사용자가
직접 설정한 값은 optimizer 결과와 달라도 덮어쓰지 않는다.

## 배경

두 경로는 후보 생성 축과 평가 순서가 다르다. 새 optimizer는 목표 평가·HARD 제약·Monte Carlo·
페르소나 배정을 수행하지만, legacy 경로는 기존 저장 데이터와 자동 반영 흐름을 보존한다.
즉시 통합하면 기존 사용자 결과와 적용 동작이 바뀔 수 있다.

## 기각한 대안과 범위 제외

한 경로만 임의로 삭제하거나 `applyAiSentinels`를 새 optimizer의 전체 후보 전략에 즉시 연결하지 않는다.
두 경로의 결과 비교와 저장·적용 회귀 검증 없이 production 경로를 전환하지 않는다.

## 호환성 처리

기존 legacy 경로와 저장 데이터는 유지한다. 화면과 PDF는 두 결과의 역할을 별도로 설명한다.
향후 전환 시에는 공통 입력에 대한 결과 비교 픽스처를 먼저 추가하고, 자동 반영·Dashboard·PDF·
저장 복원 경로를 함께 검증한다.
