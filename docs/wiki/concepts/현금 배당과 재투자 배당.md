# 현금 배당과 재투자 배당

## 한 줄 정의

같은 배당이라도 계좌 종류와 `reinvestDividend` 설정에 따라 생활비를 충당하는 현금소득이 되기도
하고, 자산 안에 그대로 남기도 한다.

## 계약

- 일반계좌에서 `reinvestDividend=false`인 배당은 세후 현금으로 지급되어 `dividendIncome`과
  생활비 충당 소득에 포함된다.
- 일반계좌에서 `reinvestDividend=true`인 배당은 은퇴 후에도 자산 내부에 남으며 현금소득으로
  잡지 않는다.
- ISA 배당은 계좌 내부에 유보·재투자되며 현금 배당소득으로 잡지 않는다.
- 사적연금은 총수익률로 성장하며 그 수익을 별도 현금 배당으로 분해하지 않는다.
- 대시보드와 PDF는 사용 가능한 현금 배당과 자산에 남은 재투자 배당을 명확히 구분한다.

이 네 구분을 종류별로 정리하면 다음과 같다.

1. 일반계좌 `reinvestDividend=false` 배당 → 세후 현금으로 지급, `dividendIncome`과 생활비
   충당 소득에 포함.
2. 일반계좌 `reinvestDividend=true` 배당 → 은퇴 후에도 자산 내부에 남고 현금소득으로 잡지
   않는다.
3. ISA 배당 → 계좌 내부 유보·재투자, 현금 배당소득 아님.
4. 사적연금 → 총수익률로 성장하며 별도 현금 배당으로 분해하지 않는다.

## 흔한 위반

- 재투자 배당이나 ISA 내부 유보 배당을 "생활비를 충당한 소득"으로 표시한다. 대시보드와 PDF는
  사용 가능한 현금 배당과 자산에 남은 재투자 배당을 구분해야 한다.
