# NextLife 사용자 매뉴얼

- 문서 기준일: 2026-08-23
- 적용 범위: 현행 production 사용자 화면

NextLife는 현재 자산·연금·기타소득과 은퇴 목표를 바탕으로 현재 계획을 분석하고, 조건을
충족하는 은퇴 전략을 비교해 추천하는 서비스입니다. 이 문서는 사용 경험에 따라 초보자,
중급자, 고급자 과정으로 나누어 설명합니다.

> NextLife의 결과는 입력값과 단순화된 계산 모델에 따른 참고 자료입니다. 미래 수익을
> 보장하거나 투자·세무·법률 자문을 대신하지 않습니다.

## 빠른 선택 가이드

| 구분 | 이런 사용자에게 적합합니다 | 먼저 익힐 기능 |
|---|---|---|
| 초보자 | 처음으로 은퇴 계획을 만들고 핵심 결과만 확인하려는 사용자 | 3단계 입력, 목표 선택, 현재 계획 진단 |
| 중급자 | 여러 가정을 비교하고 추천 전략을 실제 계획에 반영하려는 사용자 | 시나리오 비교, HARD/SOFT 목표, 추천 적용, PDF |
| 고급자 | 수익률·인플레이션·세금·건강보험료 등 가정을 직접 검증하려는 사용자 | 표준/전문가 모드, Monte Carlo, 민감도와 상세 수치 |

처음 사용하는 경우 초보자 과정을 먼저 완료한 뒤 필요한 부분만 다음 단계에서 이어서
사용하는 방식을 권장합니다.

## 모든 사용자가 먼저 알아야 할 사항

### 계정과 6자리 보안키

1. 시작 화면에서 `이메일로 회원가입`을 선택합니다.
2. 이메일 주소를 입력하고 `가입하고 보안키 받기`를 누릅니다.
3. 이메일로 받은 6자리 보안키를 입력해 가입과 로그인을 완료합니다.
4. 보안키가 담긴 이메일을 삭제하지 말고 안전하게 보관합니다.

보안키는 로그인뿐 아니라 시나리오 암호화에도 사용됩니다. 다른 기기나 시크릿 창에서 데이터를
열 때도 같은 키가 필요합니다. `데이터 초기화 및 보안키 재전송` 또는
`모든 데이터 초기화 및 새 보안키 발급`을 실행한 뒤 새 키로 로그인하면 기존 암호화 데이터와
시나리오는 삭제되며 복구할 수 없습니다.

### 저장과 개인정보 보호

- 로그인한 사용자의 시나리오는 브라우저에서 암호화된 뒤 자동 저장됩니다. 화면 상단의 저장
  상태를 확인한 후 페이지를 닫으세요.
- 서버는 시나리오의 평문 내용을 읽지 않습니다. 계산과 추천도 브라우저에서 수행됩니다.
- 시나리오 `내보내기`로 받은 JSON 파일에는 입력값이 평문으로 들어 있으므로 이메일 첨부나
  공용 저장소 업로드를 피하고 안전한 위치에 보관하세요.
- 사용자당 시나리오는 최대 5개입니다.

## 초보자: 첫 은퇴 계획 만들기

### 1. 개인정보 입력

시뮬레이터 왼쪽 입력 패널에서 `1. 개인정보`를 선택하고 다음 두 항목을 입력합니다.

- `현재 나이`: 분석을 시작할 나이
- `기대수명`: 분석을 끝낼 나이

은퇴 나이는 개인정보에서 입력하지 않습니다. 원하는 은퇴 나이는 `3. 은퇴 목표`의
`빠른 은퇴` 목표에서 정합니다.

### 2. 자산정보 입력

`2. 자산정보`에서 `보유 자산 입력`을 펼칩니다. 실제로 보유한 항목만 입력해도 됩니다.

- `주식 & ETF`: 종목, 통화, 수량, 단가, 취득원가, 적립액, 연 총수익률과 배당률
- `연금 자산`: 국민연금 예상 월 수령액과 사적연금 잔액·적립액
- `ISA 계좌`: 유형, 투자 방식, 만기, 잔액과 월 적립액
- `기타 소득`: 임대소득 등 은퇴 후에도 들어오는 월 소득

자산 카드가 접혀 있으면 카드 제목을 눌러 상세 입력란을 엽니다. 새 항목은 각 탭 아래의
`투자자산 추가`, `사적연금 추가`, `ISA 계좌 추가`, `기타소득원 추가` 버튼으로 만듭니다.

금액과 통화를 반드시 함께 확인하세요. KRW 자산은 원, USD 자산은 달러 기준으로 입력합니다.
근로소득과 배우자·가족 정보는 현재 production 입력 항목이 아닙니다. 은퇴 전 저축은 각 자산의
적립액으로 반영합니다.

### 3. 은퇴 목표 선택

`3. 은퇴 목표`에서 1개 이상, 최대 5개를 선택합니다. 처음에는 다음 조합으로 시작하기 쉽습니다.

1. `생활비 안정`: 은퇴 후 필요한 월 생활비 입력
2. `자산 고갈 방지`: 기대수명까지 자산 유지
3. 필요하면 `빠른 은퇴`: 희망 은퇴 나이 입력

선택한 목표 아래에서 위·아래 화살표로 우선순위를 바꿀 수 있습니다. 1번 목표가 가장 높은
우선순위를 갖습니다.

금액이 미리 표시되어도 `아직 제안 금액입니다`라는 안내가 나오면 그 금액은 아직 판정에
사용되지 않습니다. 금액을 검토한 뒤 `이 금액으로 확정`을 눌러야 목표 금액이 됩니다.

### 4. 분석 시작

입력 패널 위의 `분석 시작`을 누릅니다. 버튼이 비활성화되어 있다면 바로 아래 안내를 확인하세요.
주요 원인은 다음과 같습니다.

- 목표를 하나도 선택하지 않음
- 선택한 목표의 나이 또는 금액을 입력하지 않음
- `반드시 지키기`로 선택한 금액이 아직 제안 상태임
- 마지막 분석 이후 설정이 바뀌지 않음

분석은 입력할 때마다 자동 실행되지 않습니다. 입력값을 바꾼 후에는 `분석 시작`을 다시 눌러야
새 결과가 표시됩니다.

### 5. 결과를 읽는 순서

결과 화면은 `현재 계획 진단` → `NextLife 추천` → `실행 시점` → `계획의 근거` 순입니다.
앞의 세 단은 바로 보이고, 마지막 `계획의 근거`만 접혀 있습니다.

처음에는 다음 네 곳만 확인해도 됩니다.

1. `현재 계획 진단`
   - 초록: 현재 가정에서 비교적 안정적
   - 노랑: 일부 조정 또는 투자자산 소진 대비 필요
   - 빨강: 목표를 지키기 위해 계획 조정 필요
2. `목표 달성 확률`: 여러 시장 상황에서 선택한 목표의 판정 조건을 모두 지킨 시행의 비율. 충족 횟수와
   실제 미래를 보장하지 않는다는 안내를 함께 표시합니다.
3. `NextLife 추천`: 현재 계획에서 무엇을 바꾸면 목표에 가까워지는지 보여 주는 전략 카드
4. `실행 시점`: 무엇부터 바꿔야 하는지와 나이별 실행 로드맵

`은퇴 초기 생활비`는 은퇴 직후 구간에 쓸 금액입니다. `생활비 배분`을 골랐다면 그 아래 줄에
연령대별 금액이 함께 나옵니다.

`☆추천` 배지는 목표를 가장 적게 놓치는 카드를 먼저 고르고, 그중에서 목표 달성 확률과 평균
목표생활비 충족도, 자산 유지 확률, 예상 잔여자산을 함께 평가해 정합니다. 목표 달성 확률만
가장 높은 카드가 아니므로, 옆 카드의 확률이 더 높아 보여도 오류가 아닙니다. 그 근거는 카드
아래 한 줄로 함께 표시됩니다.

추천 카드는 항상 3개가 아닙니다. 조건을 충족하는 서로 다른 후보가 부족하거나 HARD 목표를
만족하는 후보가 없으면 일부 또는 전체 카드가 나오지 않을 수 있습니다. 검토한 대안이 모두
현재 계획보다 목표 달성 확률이 낮으면 `추천: 현재 계획 유지`가 대표 카드로 나오고, 나머지
카드는 참고용 대안으로 남습니다.

## 중급자: 목표와 시나리오 비교하기

### 목표 조건을 세밀하게 정하기

각 목표에는 `조건 강도`가 있습니다.

- `가능하면 달성(SOFT)`: 목표에 가까운 전략을 선호하지만 미달 후보도 비교할 수 있습니다.
- `반드시 지키기(HARD)`: 정량 판정이 가능한 조건을 충족하지 못한 후보를 추천 대상에서
  제외합니다.

생활비, 빠른 은퇴, 상속 자산처럼 값이 필요한 HARD 목표는 사용자가 나이 또는 금액을 직접
확정해야 합니다. 주거 안정, 절세, 위험 감소처럼 정량 판정 기준이 없는 목표는 우선순위가 추천
방향에는 반영되지만 HARD 달성·미달 판정에는 사용할 수 없습니다.

HARD 목표를 많이 지정하면 추천 후보가 줄거나 없어질 수 있습니다. 이 경우 목표 금액, 희망
은퇴 나이 또는 조건 강도를 검토하되, 원하는 조건을 단지 추천 카드를 만들기 위해 낮추지는
마세요.

### 시나리오를 복제하고 비교하기

1. 왼쪽의 `시나리오`에서 `관리`를 엽니다.
2. 현재 시나리오의 복제 아이콘을 눌러 사본을 만듭니다.
3. 사본 이름을 알아보기 쉽게 바꿉니다. 예: `60세 은퇴`, `국민연금 70세`.
4. 사본에서 한두 가지 가정만 바꾸고 다시 분석합니다.
5. 비교할 시나리오의 `비교`를 선택합니다.

한 번에 너무 많은 값을 바꾸면 무엇이 결과 차이를 만들었는지 알기 어렵습니다. 은퇴 나이,
생활비, 적립액처럼 한 축씩 바꾸어 비교하세요. 시나리오는 JSON 파일로 내보내거나 기존
시나리오 자리에 불러올 수도 있습니다. 불러오기는 대상 시나리오의 현재 입력값을 대체하므로
필요하면 먼저 내보내기로 백업하세요.

### 추천 전략 적용과 되돌리기

추천 카드에서 다음 내용을 먼저 확인합니다.

- 안정형·균형형·여유형 중 어떤 성격의 전략인지
- `현재 계획에서 달라지는 점`: 은퇴 나이, 국민연금 개시 나이, 인출 정책, 생활비 배분처럼
  바뀌는 **설정**
- `적용하면 달라지는 수치`: 그 설정 변경이 만든 **결과**. 국민연금 실수령액(조기수령 감액과
  연기수령 가산, 연금소득세까지 반영한 세후 월액), 은퇴 후 연평균 자산 인출액, 은퇴 후
  연평균 세금·건강보험료를 현재 계획과 나란히 보여 줍니다. 시장 변동을 반영하지 않은
  기준 수익률 경로 기준입니다.
- 목표 달성 확률과 생활비·잔여 자산의 변화

`국민연금 65세 → 60세`처럼 개시 나이만 보고 적용하지 마세요. 조기수령은 1개월당 0.5%
(5년이면 30%) 감액되고 연기수령은 1개월당 0.6%(5년이면 36%) 가산되므로, 실제 수령액은
`적용하면 달라지는 수치`에서 확인해야 합니다.

적용할 전략을 정했다면 카드의 `적용`을 누릅니다. 적용 즉시 시나리오 설정이 바뀌고 새 설정으로
분석됩니다. 결과 상단의 `적용 해제`를 누르면 적용 직전 상태로 한 번에 되돌릴 수 있습니다.
적용 전 원본을 장기간 보존하려면 먼저 시나리오를 복제하세요.

### 무엇부터 할지 확인하기

추천 아래의 `실행 시점`은 접기 없이 바로 보입니다.

- `무엇부터 바꿔야 하나`: 이미 계산된 결과에서 영향이 큰 순서로 정리한 목록
- `실행 로드맵`: 현재 설정 기준으로 나이별에 무슨 일이 일어나는지

### 계획의 근거 확인하기

`계획의 근거`에서 `자세히 보기`를 누르면 다음 내용을 확인할 수 있습니다.

- `자산 흐름`: 전체 자산과 생활비 변화, 소득·지출 구성
- `시장 변동 검증`: 위험 알림, Monte Carlo 성공률과 순서 리스크
- `계획 상세 수치`: 생활비 부족, 세금·건강보험료, 민감도

상단의 `목표 달성 확률`은 선택한 목표에서 유도된 조건을 **같은 시행에서** 함께 판정한 값입니다.
아래 두 비율은 그 판정을 이루는 성분이며, 둘을 곱하거나 더한 값이 상단 확률이 되지는
않습니다.

`목표생활비 완전 충족률`은 설정한 **연령별** 목표 생활비를 한 해도 부족 없이 충당한 비율이고,
`평균 목표생활비 충족도`는 일부 부족한 시행도 실제로 충당한 금액만큼 반영하는 비이진 지표입니다.
`기대수명까지 자산 유지 확률`은 기대수명 이전에 금융자산이 0원이 되지 않은 비율입니다. `생활비 배분`을
고르면 판정 기준도 연령대별 금액이 되며, 화면과 PDF가 그 구간을 그대로 적어 줍니다.
국민연금 등으로 생활비를 충당하면 자산이 소진되어도 생활은 유지될 수 있으므로 두 수치는
서로 다를 수 있습니다.

`계산상 최대 지속 가능 생활비`는 현재 수익률·연금·물가·기대수명 가정이 유지될 때
기대수명까지 계획이 유지되는 **계산상 상한**입니다. 권장 생활비가 아니며 위 성공률과는 다른
기준으로 계산됩니다.

`예상 건강보험료`는 현금흐름 계산값이고, `피부양자 자격 위험`은 세전 판정용 소득으로 별도
평가합니다. 재산 판정 입력은 아직 없으므로 소득 기준 이하라는 이유만으로 피부양자 자격 유지를
확정하지 않습니다. 따라서 예상 보험료가 0원이어도 자격 위험이 표시될 수 있습니다.

민감도 분석의 수익률 3행(안정형 5% / 중립형 7% / 공격형 9%)은 입력한 가정 대비 증감이
아니라 **고정된 비교 기준**입니다. 주식·ISA와 사적연금 수익률을 통째로 그 값으로 바꾸므로,
입력한 가정이 9%보다 높으면 세 행이 모두 현재 기준보다 낮게 나오는 것이 정상입니다.
화면은 그 비교를 위해 현재 가정의 가중평균 총수익률을 함께 보여줍니다.

자산 추이의 기준 수익률 경로와 Monte Carlo 중앙값도 구분하세요. 기준 경로는 매년 같은
수익률을 가정하지만, 중앙값은 해마다 수익률이 흔들리는 여러 경로의 가운데 결과입니다.

### PDF 저장

분석이 끝난 뒤 화면 상단의 `결과 다운로드`를 누르면 현재 분석을 PDF로 저장합니다. PDF 생성이
끝날 때까지 입력값을 바꾸거나 페이지를 닫지 마세요. 입력을 수정해 결과가 숨겨졌다면 먼저
`분석 시작`을 다시 실행해야 합니다.

## 고급자: 가정과 계산 결과 검증하기

### 고급 / 전문가 설정 사용하기

입력 패널의 `고급 / 전문가 설정`을 펼친 뒤 목적에 맞는 모드를 고릅니다.

| 모드 | 사용 범위 |
|---|---|
| 간편 모드 | 국민·사적연금 전략, 배당 재투자, 생활비 배분 등 핵심 항목 |
| 표준 모드 | 간편 모드 항목과 투자 전략, 경제 가정, ISA 만기 자금 |
| 전문가 모드 | 세율·과세 여부·한도·현금 수익률을 포함한 모든 노출 변수 |

모드를 바꿔도 기존 상세 설정을 삭제하지 않습니다. 간편 모드에서 보이지 않는 사용자 설정이
계산에 남아 있으면 패널의 숨은 변경 요약을 확인하세요. 기준값으로 돌아가려면 해당 설정의
되돌리기 또는 전체 `초기화`를 사용하되, 전체 초기화는 현재 시나리오의 입력값을 기본값으로
바꾼다는 점에 주의하세요.

### 수익률과 배당 입력 원칙

- `연 총수익률`은 가격 상승과 배당을 모두 포함한 전체 수익률입니다.
- `연 배당률`은 총수익률 중 현금으로 분배되는 성분입니다.
- 두 값을 더하지 마세요. 예를 들어 총수익률 8%, 배당률 2%는 합계 10%가 아니라 총 8% 중
  2%가 배당이라는 뜻입니다.
- 일반계좌는 배당 재투자를 끈 경우에만 배당이 생활비에 쓸 수 있는 현금소득이 됩니다.
- 재투자한 일반계좌 배당과 ISA 내부 배당은 자산에 남습니다. 사적연금 수익도 별도 현금
  배당소득으로 분리되지 않습니다.

수익률 자동 조회값도 미래 예측치가 아닙니다. 장기 계획에 사용할 가정이 적절한지 별도로
검토하고, 낙관·기준·보수 시나리오를 나누어 비교하세요.

### 경제·의료비·세금 가정 검증

표준 또는 전문가 모드에서는 다음 순서로 확인하면 오류를 줄일 수 있습니다.

1. `실질 수익률로 계산`과 물가상승률의 의미가 계획 의도와 맞는지 확인합니다.
2. USD 자산이 있다면 적용 환율과 대시보드 기준 통화를 확인합니다.
3. 의료비 별도 계산, 장기요양, 의료비 급증 시나리오가 중복되지 않는지 확인합니다.
4. 전문가 모드에서 세법 버전, 금융소득종합과세, 건강보험료, 해외주식 양도소득세,
   사적연금 과세와 저율과세 한도를 확인합니다.

현재 세금·건강보험료 계산은 2024년 기준의 단순화 모델이며 제도 변경을 자동 반영하지 않습니다.
실제 의사결정 전에는 최신 법령과 전문가 검토가 필요합니다.

전문가 상세의 피부양자 위험은 재산 입력이 없는 현재 제품 범위에서 소득 기준만 평가하며 최종
자격은 미판정입니다. 또한 연 1,500만원은 사적연금 저율과세 기준이지 법정 연금수령한도가
아닙니다. 법정 한도 준수 여부는 연금수령 기산연도와 과세기간 개시일 평가액이 없어 미판정으로
표시됩니다.

국민연금은 실제로 2002년 이후 납입분에 대응하는 부분만 과세되지만, 납입 이력 입력이 없어
전액을 과세 대상으로 계산합니다. 국민연금 세액이 실제보다 높게 나오며, 이것이 현재 세금
모델의 가장 큰 오차원입니다. 부양가족·추가공제를 반영하지 않는 것도 같은 방향입니다.

### 사적연금 소득이 생활비를 채운 금액보다 작게 보일 때

사적연금은 인출할 때마다 연령별 저율(3.3~5.5%)로 세금을 떼고, 연말에 그해 총 인출액을 기준으로
실제 세액을 다시 계산해 차액을 마저 냅니다. 그 정산은 생활비를 이미 쓴 뒤에 자산에서
이뤄지므로, 차트의 사적연금 금액은 그 차액까지 뺀 값인 반면 그해 생활비를 실제로 채운 돈은
그보다 큽니다. 그래서 `목표 생활비 − 사적연금 소득`이 화면의 부족액과 정확히 일치하지 않습니다.
해당 구간이 있으면 소득 구성 차트 아래에 그 금액과 함께 안내가 표시됩니다.

### 추천과 Monte Carlo를 검증하는 방법

추천 결과를 검토할 때 다음 질문을 차례로 확인합니다.

1. 현재 계획이 기준 후보로 함께 비교되었는가?
2. HARD 목표가 충족되지 않아 제외된 후보 또는 지원되지 않는 HARD 목표 안내가 있는가?
3. 추천 적용 후 목표 달성 확률뿐 아니라 생활비와 기대수명 시점 잔여 자산도 개선되는가?
4. 안정형·균형형·여유형의 목적 차이가 내 우선순위와 맞는가?
5. 민감도 분석에서 은퇴 나이, 생활비 또는 수익률 변화에 결과가 과도하게 흔들리지 않는가?

Monte Carlo는 고정 시드로 1,000회 검증해 같은 입력에서 재현 가능한 비교 결과를 제공합니다.
이는 실제 자산별 과거 수익률을 그대로 재현하거나 시장을 예측하는 모델은 아닙니다. 하위 10%,
중앙값, 상위 10% 분포와 `같은 평균, 다른 순서`를 함께 보고 은퇴 직후 하락 위험을 점검하세요.
일부 상세 분포와 비교 정보는 Pro 계정에서만 표시됩니다.

### 현재 자동 탐색 범위

NextLife가 현재 자동으로 비교하는 축은 다음 네 가지입니다.

- 은퇴 나이
- 국민연금 개시 나이
- 계좌 인출 정책
- 소비 패턴

사적연금의 독립 개시 나이, 현금 버퍼 개월 수, 동적 가드레일,
`max_sustainable` 소비 모드는 현재 production 자동 탐색 축이 아닙니다. 상세 설정이나 저장
데이터에 관련 값이 보이더라도 자동 추천이 비교했다고 해석하면 안 됩니다.

## 문제 해결

### 분석 시작 버튼을 누를 수 없습니다

버튼 아래 안내 문구를 먼저 확인합니다. 목표 1개 이상 선택, 목표값 입력, HARD 금액 확정을
마친 뒤에도 마지막 분석 이후 입력이 바뀌지 않았다면 버튼이 비활성화되는 것이 정상입니다.

### 입력을 바꿨더니 이전 결과가 사라졌습니다

이전 결과와 현재 입력이 섞이지 않도록 결과를 숨긴 상태입니다. `분석 시작`을 다시 누르세요.

### 추천 카드가 3개보다 적거나 없습니다

오류라고 단정할 수 없습니다. 조건을 만족하는 후보가 적거나 HARD 목표가 서로 충돌할 수
있습니다. 추천 영역의 제외·충돌 안내와 지속 가능한 생활비 차이를 확인하세요.

### 시장 변동성 분석 또는 추천 검증이 나오지 않습니다

브라우저가 Web Worker를 지원하지 않거나 백그라운드 계산 중 오류가 발생할 수 있습니다. 현재
계획의 기준 분석과 상세 결과는 계속 볼 수 있습니다. 최신 브라우저에서 다시 분석해 보세요.

### 다른 기기에서 시나리오가 열리지 않습니다

가입 이메일로 받은 기존 6자리 보안키를 입력해야 합니다. 보안키를 초기화하면 기존 데이터를
복구하는 것이 아니라 삭제하고 새 키를 발급합니다.

### 저장에 실패했습니다

화면 상단의 저장 오류를 확인하고 네트워크 연결 후 다시 시도하세요. 저장 완료 전에는 페이지를
닫지 말고, 필요한 경우 시나리오를 JSON으로 내보내 임시 백업합니다. 내보낸 파일은 평문이므로
안전하게 관리하세요.

## 용어 요약

| 용어 | 뜻 |
|---|---|
| 결정론적 분석 | 입력한 기준 수익률이 이어진다고 가정한 한 개의 계산 경로 |
| Monte Carlo | 수익률이 해마다 달라지는 여러 경로를 반복 계산하는 검증 |
| HARD | 정량 조건을 만족하지 못한 후보를 추천 대상에서 제외하는 강제 조건 |
| SOFT | 미달을 허용하되 목표에 가까운 후보를 더 선호하는 조건 |
| 목표 달성 확률 | 선택한 목표 조건을 같은 시행에서 모두 만족한 시뮬레이션 비율. 미래 결과 보장이 아님 |
| 목표생활비 완전 충족률 | 설정한 연령별 목표 생활비를 한 해도 부족 없이 충당한 시뮬레이션 비율 |
| 평균 목표생활비 충족도 | 전체 시행에서 목표 생활비 총액 중 실제 충당한 비율의 평균 |
| 기대수명까지 자산 유지 확률 | 기대수명 이전에 금융자산이 0원이 되지 않은 시뮬레이션 비율 |
| 계산상 최대 지속 가능 생활비 | 현재 가정이 유지될 때 기대수명까지 버티는 계산상 상한(권장액 아님) |
| 총수익률 | 가격 변화와 배당을 합친 전체 수익률 |
| 순서 리스크 | 적립기 경로는 같게 두고, 같은 은퇴 후 수익률 집합의 순서에 따라 결과가 달라지는 위험 |
