# 자동 전략 탐색 32건 추가 조사

조사일: 2026-10-29. [기존 12건 조사](자동%20전략%20탐색%20범위%20조사.md)의 후속 측정이다. 기존 탐색 축을 바꾸거나 축 확장의 효과를 비교한 실험은 아니다.

## 방법과 범위

고정 시드 `20260829`의 합성 시나리오 32건을 네 샤드로 실행했다. 앞 12건은 이전 조사와 같은 표본이므로 12건에 32건을 더해 44건으로 세면 안 된다.

```bash
SCENARIO_COUNT=32 SHARD_COUNT=4 SHARD_INDEX=0 HARNESS_OUT=/tmp/nextlife-axis-32 npm run harness:mass
# SHARD_INDEX=1, 2, 3도 같은 설정으로 실행
```

하니스는 기존 전략 컴파일·센티널·현재 계획·Monte Carlo·전략 최적화를 실행한다. 각 샤드의 테스트는 통과했다. 합성 자료이며, UI 조작·암호화 저장·정규화·브라우저 Worker까지의 왕복을 직접 검증하지 않았다. 사용자 모집단을 대표하는 표본이 아니고 상대적으로 작다.

## 판단과 미완료 검증

이번 추가 표본에서도 후보 미충족 사례가 있었지만, 새 격자 값을 실행하지 않았으므로 **탐색 축 확장의 효과는 여전히 미확인**이다. 32건은 더 넓은 탐색의 출발점이지 사용자 발생률의 추정치가 아니다.

현재 하니스는 탈락 코드와 후보 선별·검증 수를 기록하지만, `duplicateOutcomeCount`와 페르소나별 자격 탈락 원인을 행별로 기록하지 않는다. 따라서 카드 수 감소가 중복, shortlist 또는 페르소나 자격 중 무엇 때문인지 이번 결과만으로 분리할 수 없다. 기기별 메모리와 지연도 측정하지 않았다.

다음에는 하니스에 필요한 진단값을 기록하고, 12·22번 등을 포함한 사례에서 기존 후보와 격자 밖 후보를 같은 목표·평가 순서·시드·시행 수로 대조한다. 비교 결과를 해석할 때 현재 계획 보호, HARD 충족, 저장·정규화·Worker·적용 후 재현성과 후보 상한의 순회 편향도 확인한다. 이 문서는 축 확장을 승인하거나 production 기능으로 주장하지 않는다.
