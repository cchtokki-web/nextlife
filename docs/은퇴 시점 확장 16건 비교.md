# 은퇴 시점 확장 16건 비교

실험일: 2026-10-29. [3건 대조 실험](자동%20전략%20은퇴%20시점%20대조%20실험.md)의 후속이며, production 추천 축을 변경하지 않았다.

## 방법

고정 시드 `20260829`의 합성 시나리오 1~16번을 네 프로세스로 나누어 실행했다. 이전 32건의 앞부분과 겹치므로 별도 모집단으로 합산하지 않는다. 현행 격자와, 기존 65세 후보의 다른 축을 유지해 66~70세를 추가한 조사 전용 격자를 동일 profile·목표·HARD 평가·선별·페르소나 경로에서 비교했다. Monte Carlo 설정은 두 실행 모두 seed `20260101`, 확정 2,000회 및 선별 200회다. 하니스가 기존 격자를 먼저, 확장 격자를 다음에 실행한다.

```bash
COMPARISON_COUNT=16 COMPARISON_SHARDS=4 COMPARISON_SHARD=0 COMPARISON_OUT=/tmp/nextlife-retire-expanded-v2-20261029 npx vitest run --config vitest.harness.config.ts scripts/harness/retirementAgeComparison.harness.ts
# COMPARISON_SHARD=1, 2, 3도 같은 설정으로 실행. 출력 디렉터리는 실행마다 새로 사용한다.
```

각 샤드는 통과했고 시나리오별 목표 유형·우선순위·HARD/SOFT, 확정 추천·대표 후보의 달성 확률과 결정론 목표 평가, 후보 수, 경과 시간 및 실행 직후 프로세스 RSS를 기록했다. 미달 목표는 목표별 평가의 `achieved`에 따른 것이며, 별도의 HARD 위반 판정과 동일한 지표가 아니다. `no_candidate_reaches_goal`의 내부 대표 후보는 사용자 화면에 추천 카드로 표시되지 않는다.

## 결과

| 관찰 | 결과 |
|---|---:|
| 정상 완료 시나리오 | 16 / 16 |
| 현행 결과 `ok` / 최종 추천 전부 0% / 생존 후보 없음 | 14 / 1 / 1 |
| 확장 결과 `ok` / 최종 추천 전부 0% / 생존 후보 없음 | 15 / 0 / 1 |
| 양쪽 내부 대표 후보가 있는 15건 중 확률 상승 / 동일 / 하락 | 7 / 8 / 0 |
| 양쪽 내부 대표 후보가 있는 15건 중 은퇴 나이 증가 / 동일 / 감소 | 8 / 7 / 0 |
| 생성 후보 수 중앙값: 현행 → 확장 | 217 → 352 |

이는 동일한 2,000회 표본에서 나온 관찰이지 실제 미래 확률의 확정이나 사용자 발생률이 아니다. 확정된 대표 후보의 선택과 shortlist가 바뀔 수 있고, 양쪽 모두 대표 후보가 있는 경우만 확률·나이를 비교했다.

- **2번:** 세금 최적화가 1순위 SOFT다. 내부 대표 후보의 목표 확률은 71.95% → 83.15%, 은퇴 나이는 65 → 68세였다. 두 후보 모두 해당 목표가 결정론 목표 평가에서 미달로 기록됐다.
- **7번:** 연금 최적화가 1순위 SOFT, 자산 고갈 방지가 2순위 SOFT다. 현행의 최종 추천은 모두 0%라 화면에서 카드 대신 안내가 나온다. 확장 결과 내부 대표는 65 → 70세, 0% → 0.3%였지만 두 목표가 모두 결정론 평가에서 미달이었다. 2,000회 중 0.3%는 6회에 해당하는 낮은 관측치이며, 확정적인 달성 가능성이나 사용자 효용으로 해석하지 않는다.
- **8번:** 대표 후보 목표 확률은 양쪽 모두 100%, 은퇴 나이는 65 → 70세였다. 두 후보 모두 선택 목표의 결정론 평가에서 미달이 없었다. 확률의 변화가 없는데 은퇴 시점은 5년 늦어지는 사례다. 이 결과 자체만으로 사용자에게 유리하거나 불리하다고 단정하지 않는다.
- **12번:** 생활비 안정 1순위와 조기은퇴 2순위가 HARD다. 양쪽 모두 생존 후보가 없었고 추가 135개는 조기은퇴 조건에 사전 탈락했다. Monte Carlo 비교는 실행되지 않았다.
- **9번:** 상속이 1순위 HARD, 자산 고갈 방지가 2순위 SOFT다. 내부 대표 확률은 21.35% → 40.9%, 은퇴 나이는 65 → 69세였다. 현행 대표의 결정론 목표 평가에서는 두 목표가, 확장 대표에서는 상속 목표가 미달이었다. 별도의 HARD 필터와 목표 달성 문턱은 대상과 의미가 다르다.

## 비용 관찰의 한계

이 컴퓨터에서 기록한 최적화 경과 시간의 중앙값은 현행 6,083ms, 확장 5,622.5ms였고, 실행 직후 RSS는 전체 관측값에서 약 356~626MiB였다. **확장이 더 빠르다는 결론은 낼 수 없다.** 네 프로세스가 동시에 실행됐고 항상 현행을 먼저 실행해 JIT·캐시·GC·시스템 부하가 결과에 섞인다. RSS는 프로세스 실행 직후 값이며 실행별 최대 메모리나 두 격자의 독립적인 사용량이 아니다. 저사양 기기와 브라우저 Worker 측정도 아니다. 생성 후보가 늘었지만 중복 제거, HARD 탈락, shortlist와 Monte Carlo 승자 수가 달라 실행 시간이 후보 수에 비례하지 않는다.

조사 전용 생성기는 65세 격자 후보가 없으면 확장하지 않고, 이미 seed로 포함된 나이는 건너뛴다. 추가 격자에는 production 후보 상한을 재적용하거나 `axisSizes`·이론 조합 수를 재계산하지 않는다. 후보 ID가 기존 격자와 다른 접두사를 사용하므로 최종 동률에서 순서에 영향을 줄 가능성도 있다. 이 도구는 실제 확장 구현이나 성능 벤치마크가 아니다.

## 판단과 다음 검증

16건은 모두 합성 자료이고, 사용자의 선호·근로 가능 여부·실제 효과를 검증하지 않았다. 확률이 높아진 후보가 있어도 더 늦은 은퇴라는 대가와 목표 우선순위를 함께 판단해야 하므로 **production 격자 확대는 아직 결정하지 않는다**.

다음에는 후보 ID와 생성 순서·상한·shortlist의 영향을 통제한 대조, 충분한 고정 시드 표본과 목표별 사례 분석이 필요하다. 성능은 독립 실행·순서 교차·반복 측정과 저사양 기기에서 확인한다. 실제 기능으로 제안하기 전에는 UI 입력 → 암호화 저장·정규화 → Worker → 전략 적용·재분석의 도달 가능성과 결과 동등성을 검증한다.
